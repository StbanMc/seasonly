Open this page via http://, not file://

This example imports ES modules. Browsers block module imports from file:// URLs as a security measure (CORS on null origin).

From the repo root run:

npm run dev

Then open:

seasonly · banner smoke

Pick a season from the bundled Colombia calendar, then mount the banner. The banner uses Shadow DOM, so its styles never leak into this page. Try with system "Reduce motion" toggled on/off to verify accessibility.
