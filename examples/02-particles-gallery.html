Open this page via http://, not file://

This example imports ES modules. Browsers block module imports from file:// URLs as a security measure (CORS on null origin).

From the repo root run:

npm run dev

Then open:

seasonly · particles gallery

All bundled effects rendered side-by-side. Each tile is its own Shadow DOM, so styles never leak. Try toggling system "Reduce motion" — every tile should go empty (intentional: users who set that preference are explicitly asking us to stop animating).
