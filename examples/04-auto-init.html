Open this page via http://, not file://

This example imports ES modules. Browsers block module imports from file:// URLs as a security measure (CORS on null origin).

From the repo root run:

npm run dev

Then open:

seasonly · auto-init

This page mounts seasonly without writing a single line of JS. The script tag at the bottom of the page does everything via data-* attributes — the same pattern you would paste into WordPress, Shopify, Webflow, or any HTML page. 

<script type="module"
        src="../src/auto.js"
        data-locale="co"
        data-mode="banner+particles"
        data-message="Mira nuestras ofertas de temporada"
        data-cta-text="Ver más"
        data-cta-href="#hero"
        data-debug>
</script>

Open the browser console — with data-debug the lib logs exactly what it loaded and mounted.
